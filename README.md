# SPJST Scholarships — Redesign Demo

A clickable preview of the redesigned SPJST Scholarships page and its named-scholarship story pages, for review before they go live on spjst.org.

- `index.html` — main Scholarships page (apply, requirements, searchable named scholarships, giving)
- `stories/` — individual scholarship story pages

The production versions are WordPress snippets kept separately; this demo only wraps them in standalone pages and points the links at each other.
