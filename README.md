# SPJST Scholarships — Redesign Demo

A clickable preview of the redesigned SPJST Scholarships page and its named-scholarship story pages, for review before they go live on spjst.org. Two design versions are included, with the same content; the yellow bar at the top of every page switches between them.

- **Version A: Flyer style** (red, black and steel, matching the 2027 Scholarships flyer)
  - `index.html` — main Scholarships page
  - `stories/` — scholarship story pages
- **Version B: Navy & Mint** (matching the 2027 "season is open" graphic)
  - `navy/index.html` — main Scholarships page
  - `navy/stories/` — scholarship story pages

The production versions are WordPress snippets kept separately; this demo only wraps them in standalone pages and points the links at each other.
